# 产品四层与分工四域并存

Herta 装进 DSH 后有两套分类词汇，各自回答不同的问题：**产品四层**（身份/记忆/语音/界面，README 同款）回答「用户拿到的 Herta 由什么组成」；**分工四域**（界面与发布/设置与工具/语音/叙述）回答「两位开发者各自负责哪片代码」。两者刻意不对齐 —— 例如「语音」在产品层是 C 层（含 80 条 .opus 素材），在分工域里只覆盖发声代码；「叙述」在分工域存在，但产品四层里没有独立一层（它散在 B 层与 preset 行里）。两套词汇都收在 [`CONTEXT.md`](../../CONTEXT.md)，各自的 `_Avoid_` 里互相排除，讨论时按问题选一套，不在同一句话里混用。
